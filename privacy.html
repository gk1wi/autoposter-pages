Privacy Policy

Last updated: September 2026

1. What this application does

Autoposter is a content-publishing tool that connects to TikTok, Instagram, and YouTube via their official APIs to automatically publish short-form video content on behalf of the account holder who explicitly authorized the connection.

2. What data we access and why

Through the TikTok API, Autoposter accesses only:

  • The access token and refresh token issued by TikTok after the user completes the OAuth 2.0 authorization flow, used solely to publish video content to that same account.
  • Basic profile information (such as display name) strictly needed to confirm which account is connected, if requested by the relevant API scope.

No data belonging to any other TikTok user is accessed, collected, or processed. The application does not read, store, or analyze videos, comments, likes, or follower data belonging to third parties.

3. Video content

Video files published through this application are created by the account holder. They are transmitted directly to TikTok's Content Posting API for publishing and are not permanently stored by this application once publishing is confirmed.

4. Data retention

Access tokens and refresh tokens are stored only for as long as the account holder keeps the connection active. Video files are held temporarily, only for the time required to complete the publishing request, and are deleted immediately afterward.

5. Data sharing

We do not sell, rent, or share any data with third parties. Data is only exchanged with the platform APIs (TikTok, Instagram, YouTube) strictly as required to publish the authorized content.

6. Revoking access

The account holder can revoke this application's access at any time directly from their TikTok account settings (Settings → Manage apps → Autoposter → Remove), which immediately invalidates the stored access and refresh tokens.

7. Security

Access tokens are stored using encrypted, access-restricted secret storage and are never exposed in logs, source code, or shared publicly.

8. Contact

For any questions regarding this policy, please reach out through the developer's GitHub profile.
