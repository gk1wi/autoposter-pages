Política de Privacidad

Última actualización: 2026

Esta aplicación ("Autoposter") es una herramienta de automatización personal utilizada exclusivamente por su desarrollador para publicar contenido de video propio en sus propias cuentas de redes sociales (Instagram, YouTube, TikTok).

¿Qué datos maneja esta aplicación?

La aplicación únicamente procesa videos creados por el propio usuario/desarrollador para publicarlos en sus propias cuentas. No recopila, almacena, ni comparte información personal de terceros. No se recopilan datos de otros usuarios de TikTok, Instagram o YouTube.

Autenticación

La aplicación utiliza los flujos oficiales de autenticación OAuth 2.0 de cada plataforma (TikTok, Instagram, YouTube) para publicar contenido únicamente en la cuenta autorizada por el propio dueño de la aplicación. Los tokens de acceso se almacenan de forma segura y cifrada, y nunca se comparten con terceros.

Uso de los datos

El único propósito de esta aplicación es automatizar la publicación de contenido de video propio. No se utiliza para publicidad, seguimiento, ni recolección de datos con fines comerciales.

Contacto

Para cualquier duda sobre esta política, puedes contactar al desarrollador a través del repositorio de este proyecto en GitHub.
