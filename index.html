Política de Privacidad

Última actualización: 2026

Esta aplicación ("Autoposter") es una herramienta que ayuda a creadores de contenido a programar y publicar automáticamente sus videos cortos en TikTok, Instagram y YouTube.

¿Qué datos maneja esta aplicación?

La aplicación procesa únicamente el contenido de video que el usuario autorizado sube para publicar en sus propias cuentas. No recopila, almacena, ni comparte información personal de terceros, ni datos de otros usuarios de TikTok, Instagram o YouTube.

Autenticación

La aplicación utiliza los flujos oficiales de autenticación OAuth 2.0 de cada plataforma para publicar contenido únicamente en la cuenta autorizada por el usuario. Los tokens de acceso se almacenan de forma segura y cifrada, y nunca se comparten con terceros.

Uso de los datos

El único propósito de esta aplicación es automatizar la publicación de contenido de video. No se utiliza para publicidad, seguimiento, ni recolección de datos con fines comerciales.

Contacto

Para cualquier duda sobre esta política, puedes contactar al desarrollador a través del repositorio de este proyecto en GitHub.
