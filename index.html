Autoposter

Autoposter is a content publishing tool that helps creators schedule and automatically cross-post their short-form video clips to TikTok, Instagram, and YouTube.

It connects to each platform's official API using the standard OAuth 2.0 authorization flow, and publishes video content only to the account that explicitly authorized the connection.
